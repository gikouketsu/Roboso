# Roboso：カメラ画像からボールを追従する移動ロボット

立命館大学 理工学部 ロボティクス学科の授業「ロボット創造実験」（2024年度）で、4人チームで開発したロボットのソースコードです。黄色のボールをカメラで認識して追従し、回収・投擲を行います。チームとして最優秀賞（Grand Prize、2025年1月）を受賞しました。

- 動作動画：https://youtu.be/YpfJDm7KIg8
- 担当：チームリーダーとして機構・回路・プログラムを担当

## システム構成

カメラ画像の処理とモータ制御を別々の装置に分担し、画像処理の負荷がモータ制御に影響しないようにしています。

```
USBカメラ
   │
   ▼
Raspberry Pi（Python / OpenCV）
   ・カメラ取得スレッドで最新フレームを保持
   ・HSV色空間で黄色の領域を抽出し、輪郭からボールの中心を算出
   ・画面中央とのずれ（x, y）を -125〜125 に制限
   │
   │  SPI（2バイト：x, y）
   ▼
STM32（Mbed / C++）
   ・SPIスレーブとして x, y を受信
   ・ずれに応じて左輪・右輪・後輪のモータをPWMで制御
```

## ファイル構成

| パス | 内容 |
|---|---|
| `python/spi/camera_spi4.py` | Raspberry Pi側のメインプログラム。カメラ取得を別スレッドで行い、ボール検出とSPI送信を実行 |
| `python/camera/distance_camera_multithreading.py` | 初期の試作。マルチスレッドでのカメラ取得と、対象の画面中央からのずれの計算（SPI送信なし） |
| `mbed/mbed_ball_tracking.cpp` | STM32側 v1 |
| `mbed/mbed_ball_tracking_v2.cpp` | STM32側 v2 |
| `mbed/mbed_ball_tracking_v3.cpp` | STM32側 v3（未テスト） |

## STM32側プログラムの変遷

| バージョン | 内容 |
|---|---|
| v1（2024/10/17） | ずれが ±10 を超えたら旋回・前進・後退する閾値制御 |
| v2（2024/10/30） | PID制御の形で実装（Kp=0.015、Ki=Kd=0 のため実質P制御）。不感帯 ±30、出力を ±1.0 に制限 |
| v3（2024/11/6・未テスト） | Ki・Kd を追加。積分値の制限、1周期あたりの出力変化の制限（加減速の平滑化）、受信データの確認、旋回（x方向）を優先する分岐 |

## 開発環境

- マイコン：STM32、Mbed（C++）
