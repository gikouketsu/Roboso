# Mbed — STM32側ファームウェア

STM32F446REでSPIの偏差を受け取り、左右輪・後輪のPWMを設定するC++ソースです。3版は開発過程を表す資料として保存しており、配布可能なファームウェアリリースではありません。

## 版を選んで読む

| 版 | ソース | 制御内容 | 実機状態 |
|---|---|---|---|
| v1 | [mbed_ball_tracking.cpp](mbed_ball_tracking.cpp) | 固定dutyと約±10の閾値 | 版別の試験ログなし |
| v2 | [mbed_ball_tracking_v2.cpp](mbed_ball_tracking_v2.cpp) | `Kp=.015`, `Ki=Kd=0`、約±30の不感帯 | 実質P制御、検証範囲不明 |
| v3 | [mbed_ball_tracking_v3.cpp](mbed_ball_tracking_v3.cpp) | I/D項、積分制限、出力変化制限、x優先 | ソース冒頭に「未テスト」 |

## ファームウェア内の役割

| ブロック | コードの入口 | 読むときの論点 |
|---|---|---|
| PWM定義 | `PwmOut motorL_* / motorR_* / motorB_*` | 6信号、3輪、PWM周期1 ms |
| SPI受信 | `SPISlave device(...)`, `receive()`, `read()` | 2 byte目の無期限待機、フレーム同期なし |
| 返信 | `reply(0xAA)`, `reply(0xBB)` | Pi側の照合はない。ACK付き再送ではない |
| 制御計算 | `error_x/y`, `output_x/y` | v2/v3の固定dtは実行周期の計測値ではない |
| 動作出力 | `straight/back/left/right/stop` | 命令の上書きと後輪の出力保持 |
| 補助出力 | `motor1`, `motor2` | 宣言のみ。発射・回収処理なし |

## 接続と実行前の確認

SPIは `PA_7 / PA_6 / PA_5 / PA_4`、3輪PWMは `PC_8 / PC_6 / PA_9 / PA_8 / PB_3 / PA_10` です。[信号一覧](../electronics/interfaces.md)から基板とコードを照合できます。

完全なMbedプロジェクト、Mbed OSの固定版、ビルドプロファイル、コンパイラ版は公開されていません。新規プロジェクトで再構築する場合は、対象ボード・ライブラリ・ピン割当てを先に確認し、3つのファイルから1つだけを `main.cpp` として選ぶ必要があります。3ファイルを同時にビルドすると `main()` やグローバル定義が重複します。これは再構築時の注意であり、再現済みビルド手順ではありません。

v1/v2の停止出力は `1,1`、v3は `0,0` です。入力真理表と実配線の照合なしに停止・制動の意味を決められません。通信タイムアウトや目標消失時の停止保証もありません。駆動系を接続する前に、負荷を切り離して受信値とPWM波形を観測する段階が必要です。

## 改良を進める順序

1. モータ関数の全出力を毎回明示し、運動命令を1周期に1つに決める。
2. 通信途絶・目標消失を検出する停止経路を設ける。
3. 受信処理と制御周期を分離し、実時間のdtを計測する。
4. P制御から再評価し、根拠となるログを残してI/D項を検討する。

この順序は今後の提案です。原ソースへの修正や実機検証を完了したという意味ではありません。
