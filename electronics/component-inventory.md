# 部品・設計資料の棚卸し

元の部品表と回路図が揃っていないため、この一覧は発注用BOMではありません。確認できる構成要素と、再製作のために不足する情報をまとめています。

| 要素 | 根拠のある情報 | 数量・型式の確度 | 不足情報 |
|---|---|---|---|
| 上位計算機 | Raspberry Pi、Python/OpenCV | 報告で4/4Bと5が混在 | 実機型番、OS、電源条件 |
| 制御MCU | STM32F446RE | 報告記述 | ボード版、Mbed環境 |
| カメラ | USB / `VideoCapture(0)` | 型式未確定 | 解像度、フレームレート、露出 |
| オムニホイール | 120°配置の3輪 | 駆動輪は3 | 径、ローラ仕様、取付寸法 |
| モータドライバ | 報告にTB67H450の記述、3系統の接続レイアウト | 実装全体は未照合 | モジュール版、真理表、定格、保護 |
| 駆動モータ | 左・右・後輪のPWM定義 | 駆動系は3、全モータ数は報告内で不一致 | 型式、ギヤ比、電流、回転特性 |
| 機構用モータ | 発射機構の試作画像 | 型式・総数未確定 | トルク、電源、制御方法 |
| DC-DC / 電源 | 電源安定化・分離の報告 | 型式未確定 | 入出力、効率、放熱、保護 |
| 3Dプリント部品 | CAD画像と試作写真 | 元CADなし | 材料、STL/STEP、印刷条件、公差 |
| 基板 | 拡張・ドライバ配線の2種類の画像 | レイアウト記録のみ | EDA、回路図、Gerber、ERC/DRC |

型式の一致と製造可能な資料が揃ってから、確定BOMを作成します。報告でモータ数が4/5/6と異なる点を、推測で一つに統一していません。
