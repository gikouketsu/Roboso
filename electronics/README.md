# Electronics — 制御基板・モータ駆動・電源

画像処理ノード、STM32、モータを接続する電子回路の入口です。報告に残るSTM32拡張基板とモータドライバ配線基板のレイアウトを、公開ソースの信号定義と対応させています。

## STM32拡張基板

![STM32拡張基板のレイアウト](../media/electronics/stm32-expansion-pcb-layout.jpg)

基板上でSTM32周辺の信号をまとめる設計です。公開コードからSPI 4信号と、左右・後輪の2入力ずつのPWMを確認できます。[コードとの対応表](interfaces.md)で各ピンを追えます。

## モータドライバ配線基板

![3系統ドライバのレイアウト](../media/electronics/motor-driver-pcb-layout.jpg)

報告に示される3系統のドライバ接続用レイアウトです。報告中にはTB67H450の記述がありますが、全実装部品・結線・保護回路の確定には元回路図と実機の照合が必要です。これらの画像は製造可能なEDA/Gerberデータではありません。
