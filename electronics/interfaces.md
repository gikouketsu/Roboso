# インターフェースと信号定義

以下は公開ソースにある定義です。実機の導通やコネクタの端子番号を検証した配線図ではありません。

## Raspberry Pi — STM32

| 信号 | Pi側ソフトウェア | STM32側定義 | 方向 |
|---|---|---|---|
| MOSI | SPI bus 0 / device 0 | `PA_7` | Pi → STM32 |
| MISO | SPI bus 0 / device 0 | `PA_6` | STM32 → Pi |
| SCLK | `max_speed_hz=115200` | `PA_5` | Pi → STM32 |
| CS / SS | device 0 | `PA_4` | Pi → STM32 |
| GND / 基準電位 | コードでは規定しない | コードでは規定しない | 実回路で確認 |

Piの物理ヘッダ番号、コネクタの向き、レベル変換、SPIモードと配線長は資料から確定していません。コードのバス指定だけを元に接続せず、実機と端子表を照合します。

## モータ出力

| 機能 | 入力1 | 入力2 | 使われ方 |
|---|---|---|---|
| 左輪 | `PC_8` | `PC_6` | `motorL_1/2` |
| 右輪 | `PA_9` | `PA_8` | `motorR_1/2` |
| 後輪 | `PB_3` | `PA_10` | `motorB_1/2` |
| 補助1 | `PB_10` | 未定義 | `motor1`、出力処理なし |
| 補助2 | `PB_5` | 未定義 | `motor2`、出力処理なし |

3輪のPWM周期は1 msです。`straight/back` は後輪を更新せず、v1/v2とv3は `stop()` の入力組合せが異なります。回路の真理表と突き合わせる必要があります。

## データの意味

| 項目 | 定義 |
|---|---|
| x | 検出円中心の整数x座標 − 画像幅の半分 |
| y | 検出円中心の整数y座標 − 画像高さの半分 |
| 単位 | pixel、物理距離ではない |
| 飽和 | 各軸を `-125..125` に制限 |
| byte順 | x → y |
| 負数 | `value & 0xFF` による2の補数表現 |
| 応答 | MCUは `0xAA/0xBB` を準備、Piは戻り値を照合しない |

例えば `x=-51, y=-39` は `[205,217]` です。[オフライン確認ツール](../python/tools/inspect_packet.py)でこの変換を確認できます。ツールの成立は実SPI通信の成立を意味しません。
