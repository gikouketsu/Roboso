# 14. 受賞

## 公開情報

プロジェクトは、リポジトリ所有者が従来から公開しているプロジェクト情報に基づき、**4名チームとして最優秀賞（2025年1月）**を受賞したと記録しています。

## 根拠の境界

- これはチーム受賞であり、本人の単独受賞ではありません。
- 非公開の46ページの実験報告書には、賞状、審査結果、順位表は含まれていません。
- 現在のリポジトリに賞状写真や公式発表の一次資料は含まれていません。
- したがって、受賞から投擲精度、通信信頼性、連続稼働の定量性能を推定しません。

追加で公開する場合は、主催者名、賞名、日付を確認でき、他メンバーの氏名や学籍情報を公開しない一次資料のみを追加する方針です。
