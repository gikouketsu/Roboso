# 13. 既知の制約

## 機能の完成度

- 回収機構の制御は未完了です。
- システム全体の自律的な「検出 - 追従 - 回収 - 発射」閉ループは完了として扱えません。
- 公開コードに発射・回収用の補助モータ出力処理はありません。
- オムニホイール・シャーシの運動学式は設計資料にありますが、公開コードは任意方向の連続的な速度分配を実装していません。

## 制御と通信

- v2は `Ki=0`, `Kd=0` のためP制御相当です。
- v3は未テストです。
- v1/v2に命令上書きの可能性があります。
- PID式の `dt=1 ms` は実測周期に結び付いていません。
- SPIは2 byteのみで、header、length、sequence、checksum / CRC、timeout、retryがありません。
- STM32の `0xAA/0xBB` 応答をRaspberry Piが照合していません。
- 目標消失または通信途絶時のウォッチドッグ停止がありません。

## 画像処理

- 固定HSVしきい値で、照明変化への適応はありません。
- 複数輪郭のうち1目標を選ぶロジックがありません。
- 検出信頼度、フレームID、タイムスタンプを送信しません。
- 実質的な3D位置推定を行うカメラキャリブレーションは公開コードにありません。`distance_x/y` はメートル単位の距離ではなく、ピクセル偏差です。

## 機構と電気

- 発射精度、繰り返し性、連続運転は未検証です。
- PDF 17-19ページの発射力学モデルは単位と数値に不整合があり、実測性能に使用できません。
- モータドライバの入力真理表と実配線がなく、`stop()` の電気的意味を検証できません。
- 電流、電圧降下、発熱、リップル、ノイズの定量記録がありません。
- 報告中でRaspberry Pi 4/4BとBOMのRaspberry Pi 5、モータ数4/5/6の記述が一致していません。実機写真と配線からの再確認が必要です。

## 性能評価

- ボール追従成功率、停止誤差、追従速度の統計値がありません。
- エンドツーエンド遅延、制御ジッタ、SPIエラー率の測定がありません。
- 発射飛距離の「実測」とされた曲線に計測方法、試行数、元データ、誤差棒がありません。このリポジトリでは性能根拠として使いません。

## 再現性と資料

- Mbedの完全なビルドプロジェクトがありません。
- 元のCAD、STL / STEP、回路図、EDA、Gerber、Matlabスクリプト、実験生データがありません。
- 完全な46ページ報告書は、個人情報とチームの知的財産を保護するため公開していません。
