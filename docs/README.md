## 根拠の強さ

| ラベル | 意味 |
|---|---|
| コード確認 | 現在の公開ソースに該当実装がある |
| 報告記録 | 当時のチーム報告に写真・図・記述がある |
| 試作 | 形状または基本動作の記録があるが、定量評価はない |
| 設計のみ | 目標または構想。実装完了を意味しない |
| 未検証 | 再現手順、計測値、長時間試験などの根拠がない |
