# 12. チームと本人の貢献

## 開発体制

このロボットは4名チームの共同成果です。個人の作品として整理する際も、ロボット全体、機構、基板、受賞を本人が単独で完成させたものとは表現しません。

## 本人が担当した範囲

| 分野 | 具体的な貢献 | 関与の形態 |
|---|---|---|
| チームリード | 進捗確認、日程・リソース調整、機構・回路・ソフト間のインターフェース調整 | 本人の担当 |
| 発射機構 | ハードウェア担当者と協働した設計・試作・改修 | **共同作業** |
| 機構改良 | 角度誤差、発射力の不安定、振動に対応する約11回の改修 | 本人を含む協働作業 |
| 回路 | 電源分離の検討、STM32拡張・モータドライバ基板、配線統合 | 本人が関与 |
| 通信 | Raspberry Pi - STM32間のSPIプロトタイプ | 本人が実装に関与 |
| 画像処理 | OpenCVによる色領域検出と偏差算出 | 本人が実装に関与 |
| 制御 | STM32の受信、PWM、閾値/PID形式の試作 | 本人が実装に関与 |

他のメンバーの氏名と個人別の詳細は、プライバシーとチームの知的財産を守るため公開していません。

## リーダーシップの実体

リーダーとしての中心的な課題は、単一部品の設計よりも、「各サブシステムがどの信号とエネルギーを受け取り、どの条件で次のサブシステムに渡すか」の調整でした。

- 機構側の負荷と振動を回路・電源側の制約と照合する
- 画像処理側の出力を、MCUが扱える小さなプロトコルに定義する
- 各担当の作業が個別に動く状態から、統合システムとして組み合わせる
- トラブル時に機構、電源、通信、制御の境界を切り分ける

## 成果の境界

- 回収機構の制御は実験期間中に完成しませんでした。
- 投擲精度、長時間安定性、PID改良版は十分に検証されていません。
- 受賞はチームの成果であり、個人の単独受賞ではありません。
