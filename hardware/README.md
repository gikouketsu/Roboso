# Hardware — 機構設計と実機統合

車体・オムニホイール・発射機構・実装空間を扱うハードウェアの入口です。報告に残るCAD画像と実物写真から、設計と試作の関係を追えるようにしています。

![全体CADと実機](../media/overview/robot-cad-and-prototype.jpg)

## 構成

| モジュール | 設計上の役割 | 確認できる成果 | 詳細 |
|---|---|---|---|
| 車体 | 3輪、制御基板、配線、機構を保持 | 全体CADと組立写真 | [シャーシ](../docs/02-omni-chassis.md) |
| オムニホイール | 車体周囲に120°で配置 | 幾何図と写真 | [機械設計](mechanical/README.md) |
| 発射機構 | ラック・ピニオンとスライダによる押し出し | CAD、3Dプリント試作、基本動作の報告 | [発射機構](../docs/03-launcher-mechanism.md) |
| 回収機構 | ボールを取り込む | 構想・試作ハードウェア | 制御は未完了 |
| 実装・配線 | 電源・制御・駆動系を車体へ配置 | 実物写真とPCBレイアウト | [統合手順](integration.md) |

## 発射機構の設計と試作

![発射機構のCADと試作](../media/mechanics/launcher-cad-and-prototype.jpg)

報告では発射機構の角度誤差、力の不安定、振動に対応する約11回の改修が記録されています。画像から形状と試作の存在は確認できますが、各版のCAD差分・寸法・評価表は未提供です。反復改良の過程と、性能を測定できていることは分けて扱います。

## 提供されている設計資料

| 資料 | 公開状態 | 用途 |
|---|---|---|
| 全体CAD・機構CAD | 報告から抽出した画像 | 構成と設計意図の説明 |
| 3Dプリント部品 | 試作写真 | 製作物の確認 |
| 原CAD・STL・STEP | 未提供 | 寸法変更・再製作には不足 |
| 材料・印刷条件・公差表 | 未提供 | 強度や再現性の評価には不足 |
| 投擲の反復測定 | 未提供 | 精度・繰り返し性は未検証 |

スクリーンショットから寸法を推定して製造データに置き換えることはしていません。
