# Mechanical Design — 車体と発射機構

## 3輪配置とソフトウェアの関係

![120°オムニ配置](../../media/chassis/omni-wheel-geometry.jpg)

3輪を120°で配置し、報告では中心から車輪までを `R=173 mm` としています。これは設計上の値で、完成車体の寸法検査値ではありません。オムニホイールの運動学式は[シャーシ詳細](../../docs/02-omni-chassis.md)にあります。

設計式は並進と回転を3輪の速度に変換しますが、公開ソフトウェアはその行列を実装せず、前後進と旋回の関数を選ぶ構成です。機械的に全方向移動が可能な配置と、任意方向速度を実装した制御は同じではありません。

## ラック・ピニオン式の発射試作

![機構の往復動作](../../media/mechanics/launcher-motion-sequence.jpg)

| 要素 | 役割 | 再製作時に必要な情報 |
|---|---|---|
| ホッパ | ボールを供給位置に保持 | 内径、出口、ボールとのクリアランス |
| ピニオンとラック | 回転を直線運動へ変換 | 歯形、モジュール、噛合い、ストローク |
| スライダ | ボールを押し出す | 摺動抵抗、案内、終端位置 |
| モータ支持 | 回転軸と機構の相対位置を保持 | 取付寸法、締結、変形・振動 |
| 車体との結合 | 反力を受け、位置を保持 | 取付点、剛性、重心への影響 |

右欄は原CADや実機で確認する情報です。現在の資料から数値を確定していません。

## 評価すべき切り分け

最初に無負荷のストロークと引っ掛かりを観察し、次に単発の供給・押し出し、最後に反復供給と車体上での振動を確認する順序が考えられます。各段階で入力条件と失敗事象を記録すれば、供給・摺動・駆動・構造のどこが原因かを絞れます。これは再評価の提案であり、実施済み試験ではありません。

報告の発射計算には単位と数値の不整合があります。飛距離や発射速度の性能根拠に使用せず、[発射機構詳細](../../docs/03-launcher-mechanism.md)で疑点を明示しています。
