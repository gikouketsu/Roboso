# Hardware / Software Integration

このページは公開資料で未確認の点を含む、再立ち上げ時の作業順序です。実施済みの受入試験や、完全な組立説明書ではありません。

## 接続境界を整理する

| 境界 | 渡すもの | 照合先 | 未確認事項 |
|---|---|---|---|
| カメラ → Pi | BGRフレーム | `cv2.VideoCapture(0)` | カメラ型式、解像度、露出 |
| Pi → STM32 | SPIの符号付き偏差2 byte | [信号一覧](../electronics/interfaces.md) | 実配線、モード、CS波形 |
| STM32 → ドライバ | 3輪分のPWM 6信号 | [Mbed](../mbed/README.md) | 入力真理表、極性、PWM対応 |
| 電源 → ロジック / 駆動 | DC電力 | [電源](../electronics/power.md) | 電圧、電流、保護、配線経路 |
| モータ → 機構 | トルク・反力 | [機械設計](mechanical/README.md) | 電流・ストローク・振動 |

## 段階的に組み合わせる

| 段階 | 作業 | 次へ進むために記録すること |
|---|---|---|
| 1. 静的照合 | 回路、信号名、ピン、電源極性を確認 | 確定した配線表と定格 |
| 2. ロジック単体 | 駆動負荷を切り離し各ノードを確認 | 電源電圧、起動、リセット |
| 3. 通信単体 | 既知のx/yを転送して受信と波形を観察 | 値、順序、CS、SPIモード |
| 4. 個別モータ | 車体を浮かせて1輪ずつ出力 | 正方向、停止入力、始動電流 |
| 5. 命令遷移 | 旋回・前後進・停止を組み合わせる | 全輪PWMと前出力の残留 |
| 6. 画像と駆動 | 目標の位置と消失を変える | 誤指令、停止条件、処理遅延 |
| 7. 機構・反復 | 発射試作と車体への影響を確認 | 給球失敗、振動、温度、試行数 |

現在のソフトウェアには通信切断・目標消失時の停止保証がありません。負荷試験を始める前に停止出力の電気的意味と、電源を遮断できる方法を確認する必要があります。

## 記録の形式

試験ごとに、日付、ソースのcommit、ファームウェア版、実配線版、電源、入力、観測方法、結果、再現条件を残します。成功例だけでなく未検出、取りこぼし、再起動、引っ掛かりを区別すると、ハードウェアとソフトウェアの原因が混ざりにくくなります。

測定値を残す際は[試験マトリクス](../docs/10-verification.md)のIDに対応させます。当時の元ログは未提供のため、ここには架空の測定結果を置いていません。
